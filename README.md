# Portofolio Daniel Ardiyansah

Website portofolio pribadi menggunakan HTML dan CSS sederhana.

## Deskripsi
Proyek ini dibuat untuk Tugas Akhir Praktikum Pemrograman Web (Modul 2: Git & Version Control).
Berisi implementasi lengkap workflow Git mulai dari inisialisasi, branching, hingga push ke GitHub.

## Instalasi
1. Clone repository ini:
git clone https://github.com/superboy12/portofolio-daniel.git
2. Buka folder proyek
3. Jalankan file `index.html` di browser

## Teknologi
- HTML5  
- CSS3  
- Git & GitHub
